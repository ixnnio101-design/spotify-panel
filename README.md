# Spotify Panel — 3D World Hologram

Клиентский мод для **Minecraft Java 1.21.11 / Fabric**. Панель находится непосредственно в игровом мире: это объёмный объект с корпусом, глубиной, рамкой и отдельными мини-панелями плейлистов. Экранный HUD/GUI для отрисовки плеера отключён.

## Что отображается

- Обложка альбома и текущий трек берутся из данных Spotify.
- Название трека, исполнитель, состояние воспроизведения, прогресс и громкость рисуются в динамическую текстуру Java-кодом.
- На каждый плейлист создаётся отдельная небольшая 3D-панель с собственной динамической текстурой. Количество мини-панелей зависит от количества плейлистов; они располагаются в сетке 3 колонки под основным плеером.
- Модель следует за поворотом торса игрока, а не за направлением камеры: её можно видеть под перспективой с разных углов.
- При открытом чате (T) можно нажимать на кнопки и полосы прямо на объёмной панели; на мини-панель плейлиста можно нажать, чтобы запустить его.

Корпус и рамка создаются как мировая 3D-геометрия. Динамические текстуры используются только для содержимого поверхностей, а не как экранный GUI.

## Команды

- `/spotify` — показать/скрыть голограмму.
- `/spotify setup <client_id>` → `/spotify login` — подключить Spotify.
- `/spotify playlist add <ссылка>` — добавить плейлист по ссылке, URI или ID.
- `/spotify playlist remove <ссылка>` — убрать плейлист, добавленный вручную.
- `/spotify proxy <host:port>` — HTTP-прокси; `/spotify proxy off` — выключить.
- `/spotify play|pause|toggle|next|prev|volume <0-100>` — управление командами.

## Важное про Spotify API

Прокси может помочь при сетевых проблемах, но не обходит ограничения доступа Spotify API. Доступность списка треков зависит от прав приложения и конкретного плейлиста.

## Сборка

Проект использует Gradle Wrapper и Java 21. Запуск сборки: `./gradlew build` (Windows: `gradlew.bat build`).
