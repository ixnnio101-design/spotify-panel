# Spotify Panel — 3D World Hologram

Клиентский мод для **Minecraft Java 1.21.11 / Fabric**. Панель находится непосредственно в игровом мире: это тонкая плоская многослойная модель Spotify, расположенная в мировых координатах, с небольшими разносами слоёв по глубине. Экранный HUD/GUI для отрисовки плеера отключён.

## Что отображается

- Обложка альбома и текущий трек берутся из данных Spotify.
- Название трека, исполнитель, состояние воспроизведения, прогресс и громкость рисуются в динамическую текстуру Java-кодом.
- Основная форма панели загружается из `assets/spotify-panel/models/panel.bbmodel` — это твоя плоская модель Blockbench с 13 отдельными частями.
- Каждый элемент из Blockbench отрисовывается как плоская поверхность в мировых координатах. Исходные координаты X задают только небольшой разнос слоёв по глубине; искусственная толщина и боковые грани не добавляются.
- Статичная текстура материала корпуса находится в `assets/spotify-panel/textures/misc/panel_material.png`.
- Прозрачный динамический слой показывает обложки, название трека, исполнителя, список треков выбранного плейлиста, прогресс и громкость. Он накладывается на поверхность модели, а не на экран.
- Левая колонка показывает единую медиатеку: плейлисты, сохранённые альбомы, любимые треки, исполнителей, подкасты, сохранённые эпизоды и аудиокниги. У каждого типа есть маленькая буквенная/символьная метка поверх обложки. Если элементов больше семи, колонку можно прокручивать колёсиком мыши при открытом чате. Клик по иконке поддерживаемого раздела запускает первый доступный элемент: для плейлиста/альбома — первый трек, для «Любимых треков» — первую сохранённую песню. Если содержимое плейлиста недоступно через Spotify API, мод пытается запустить сам контекст плейлиста.
- Панель прикреплена близко к верхней части торса и ориентируется по интерполированному yaw тела игрока, а не по yaw камеры; сглаживание добавлено только между игровыми тиками, чтобы уменьшить дрожание. Освещение поверхности фиксировано, поэтому яркость не должна меняться при развороте панели.
- Текст выводится непосредственно в финальную динамическую текстуру с включённым сглаживанием и дробными метриками: без искусственного уменьшения/увеличения глифов. Пиксельный характер оставлен в геометрии рамок, кнопок и акцентах, чтобы названия на наклонённой мировой панели не превращались в нечитаемые блоки. Выбранный плейлист показывает собственную обложку в верхней шапке, отдельно от обложки текущего трека справа. Градиент шапки строится по цветам обложки; сами обложки остаются чёткими и не пикселизуются.
- Цвет верхней шапки вычисляется по цветам выбранной обложки: для насыщенных обложек строится цветной градиент, для почти монохромных — нейтральный серый, как в Spotify.
- При открытом чате (T) можно выбирать и запускать плейлисты и треки, управлять воспроизведением, перематывать и менять громкость кликами по поверхности модели. Громкость и позицию трека можно менять, зажав ЛКМ на соответствующем ползунке и перетаскивая его. Обычное колесо мыши прокручивает левую библиотеку и список треков.

`panel.bbmodel` хранится внутри ресурсов мода и загружается при запуске. Текущий импортёр использует плоские элементы без вращения — именно так устроена присланная модель. Он использует координаты и названия 13 элементов; UV-развёртка из файла пока не применяется, потому что в присланной модели ещё не было назначенной текстуры. Материал корпуса задаётся отдельным PNG, а живое содержимое — прозрачным слоем Java. Если в Blockbench изменить геометрию, замени этот файл в ресурсах; при добавлении вращённых кубов импортёр потребуется расширить.

## Команды

- `/spotify` — показать/скрыть голограмму.
- `/spotify setup <client_id>` → `/spotify login` — подключить Spotify.
- `/spotify playlist add <ссылка>` — добавить плейлист по ссылке, URI или ID.
- `/spotify playlist remove <ссылка>` — убрать плейлист, добавленный вручную.
- `/spotify logout`, затем `/spotify login` — заново выдать Spotify дополнительные права после обновления мода.
- `/spotify proxy <host:port>` — HTTP-прокси; `/spotify proxy off` — выключить.
- `/spotify play|pause|toggle|next|prev|volume <0-100>` — управление командами.

## Важное про Spotify API

Панель загружает разные разделы отдельными запросами Spotify Web API: `/me/playlists`, `/me/albums`, `/me/tracks`, `/me/following?type=artist`, `/me/shows`, `/me/episodes` и `/me/audiobooks`. Для этого OAuth-запрос теперь просит `user-library-read` и `user-follow-read` вместе с правами чтения плейлистов и управления воспроизведением. После обновления мода нужно один раз заново выдать разрешения: `/spotify logout`, затем `/spotify login`. Если конкретный раздел недоступен для приложения/аккаунта или Spotify вернул 403/429, остальные успешно загруженные разделы всё равно остаются доступны. Spotify ограничивает получение содержимого некоторых плейлистов: список может показывать плейлист, но его треки доступны через API только если пользователь владеет им или является соавтором. Spotify также может применять отдельные ограничения Developer Mode и региональной доступности; мод не обходит такие ограничения.

## Сборка

Проект использует Gradle Wrapper и Java 21. Запуск сборки: `./gradlew build` (Windows: `gradlew.bat build`).


### Latest playback fixes

Clicking a playlist icon opens the playlist and starts its first available track. Selecting a track in Liked Songs starts it through its album context and exact track offset; the panel's Next/Previous controls then follow the saved-tracks list rather than the album. The volume slider updates locally immediately and coalesces outgoing Spotify API requests to avoid a queue of stale values.
