Обновление текстового блока LRCLIB

- Добавлена цельная зелёная рамка в цвет акцента Spotify вокруг карточки текста песни.
- Заголовок внутри карточки не добавляется: свободное место используется под строки.
- Синхронизированные строки плавно перемещаются в область просмотра; яркость активной строки также меняется плавно.
- Длинные синхронизированные и обычные строки автоматически переносятся по словам.
- Слишком длинные слова делятся по Unicode-кодовым точкам, без обрезания троеточием.
- Прокрутка обычных текстов учитывает перенесённые визуальные строки.
- Тексты LRCLIB между треками не кэшируются. В памяти хранится только временная разметка текущего ответа, чтобы не пересчитывать переносы каждый кадр.
- Частичная отрисовка, 3D-привязка и стабилизация камеры сохранены.

ИСПРАВЛЕНИЕ ПОДСВЕТКИ ПЕРЕНЕСЁННЫХ СИНХРОНИЗИРОВАННЫХ СТРОК
- Все визуальные фрагменты одной исходной LRC-строки (которые появились после переноса по ширине карточки) теперь получают одинаковую активную подсветку и жирное начертание. Раньше выделялся только первый визуальный фрагмент.
- Переход подсветки между исходными временными строками остаётся плавным: предыдущая строка/группа мягко затухает, следующая группа проявляется; при быстрой смене тайминга переход начинается с текущего промежуточного положения.
- Неактивные строки уменьшены с 13 до 11 px; активная строка/группа остаётся 14 px Bold, поэтому синхронизация читается заметнее.
- Синхронизированные фрагменты переносятся с учётом метрик активного жирного шрифта, чтобы выделенная строка не выходила за ширину карточки. Обычный несинхронизированный текст размечается по меньшему шрифту.
- Источник LRCLIB, отсутствие межтрекового кэша, 3D-модель, рамка Spotify-green, частичная отрисовка и стабилизация камеры не менялись.
