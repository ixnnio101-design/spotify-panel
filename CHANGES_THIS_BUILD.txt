Changes in this build

- Kept the restrained half-pixel visual style in panel shapes, borders and controls; typography is now rendered with normal antialiased glyphs for legibility.
- Replaced rounded UI panels and controls with square surfaces, stepped corner frames, rectangular sliders, pixel-shaped play controls, and a cover-colour header gradient rendered in horizontal colour bands.
- Updated the panel material texture to a low-contrast 4x4-pixel grain so surfaces have a subtle pixel texture without competing with album artwork or text.
- Album and playlist cover art stays high-resolution; only typography and UI decoration use the pixel treatment.
- Kept the previous world-space positioning, one-block forward anchor, single-pass flat Blockbench geometry, dynamic Spotify text/cover overlay, and left-mouse drag controls for volume and seeking.

Build command on Windows: gradlew.bat build
Minecraft target: 1.21.11 / Fabric


Playback and input responsiveness fixes

- Volume dragging now updates the local slider immediately and coalesces Spotify requests: at most one request is in flight, with only the latest drag value kept pending. This prevents a backlog of stale volume commands.
- The world-space overlay refreshes at a faster interval while a slider is being dragged, so the visible knob/bar follows the cursor more closely without repainting the full texture every frame.
- Clicking a supported library entry in the left column starts its first playable item: the first track in a playlist or album, or the first saved song in Liked Songs. If playlist contents cannot be read through the Spotify API, the mod attempts to start the playlist context directly.
- Clicking a song inside Liked Songs now starts that song with its album as the playback context and the song as the offset. This avoids the bare-URI playback path that can make Spotify Desktop clear playback on some recent clients.

World-space text/render cleanup

- Removed the half-resolution glyph rasterizer that enlarged aliased glyphs and produced blocky streaks/overlapping-looking text on the world-space plane. All labels now render directly at final texture resolution.
- All UI text is now drawn directly at final texture resolution with antialiasing and fractional metrics enabled. The pixel-inspired look remains in panel frames, controls and surfaces only.
- Reduced oversized heading/track typography and changed the table to five larger, better-spaced rows to fit the thin world-space panel.
- Made text/table surfaces more opaque so background material cannot show through the lettering.
- Moved the live overlay slightly farther in front of the Blockbench surfaces to reduce depth overlap.


Smooth controls and scrolling

- The visible volume and playhead are eased locally at frame rate, independently from Spotify polling, so the controls do not jump between snapshots.
- Volume HTTP updates are coalesced and sent in smaller steps; seeking remains a local preview while dragging and commits once on mouse release to avoid repeated playback stutter.
- The progress indicator stays locked to a smoothly interpolated mouse preview while the seek slider is held, rather than drifting forward with playback time.
- Playlist/sidebar and track-table wheel scrolling now animate with slower frame-time easing and fractional row offsets for a softer glide.
- Track row numbers use the absolute item index, so scrolling past the first page continues with 6, 7, 8, etc. instead of resetting to 1-5.
- The playing-row highlight now matches the exact Spotify track URI, avoiding false matches on duplicate song titles, and uses a restrained full-row accent.
- Switching between library entries fades and subtly slides the new header and track table in instead of replacing them abruptly.


Final interaction polish

- Seeking now behaves like a normal scrubber: the timeline preview follows the held mouse smoothly, and only one seek request is sent on release. This prevents repeated remote seeks from stuttering playback during the drag.
- Volume changes are eased on the Spotify device in smaller 8-point steps, with a short request interval and latest-target coalescing. The visible on-panel value is separately interpolated for a smooth response.
- The playback timeline locks to the dragged preview and does not creep forward underneath the cursor.
- Both library and track lists use eased fractional scrolling; row numbers continue from the true item index after scrolling.
- Now-playing row detection uses Spotify URIs rather than title-only matching, with a cleaner green row treatment.

Additional animation polish

- Visible volume and playhead values use frame-time interpolation; progress follows the local drag preview smoothly and is committed only once after release.
- The now-playing row highlight fades between track URIs instead of abruptly switching its background, border and text tint.
- Scroll easing was softened and selection changes now use a gentle fade plus a small vertical settle.
- Dragging and scrolling refresh the world-space texture at up to 60 FPS; normal playback refresh stays lighter.
